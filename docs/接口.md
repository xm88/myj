# HTTP 与 WebSocket

除了健康检查、配置、武器列表和登录，其他接口都要 `Authorization: Bearer <jwt>`。失败体是 `{ "error": "中文原因" }`。

开发时网页把 `/api` 和 `/ws` 代理到 `127.0.0.1:8787`。

## 登录

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/auth/register` | `{ email, password }`，返回 token，还没有角色 |
| POST | `/api/auth/login` | 邮箱密码 |
| POST | `/api/auth/guest` | 创建游客和默认剑盾角色，直接返回 token |
| POST | `/api/characters` | `{ name, weaponType }` |
| GET | `/api/profile` | 档案。没有角色时是 404 |
| GET | `/api/config` | 地图、怪物、物品、技能、配方、派遣点 |
| GET | `/api/health` | 版本、天气、是否打开测试开关 |

`weaponType`：`sword_shield`、`greatsword`、`staff`、`bow`。

| 方法 | 路径 | 主体 |
| --- | --- | --- |
| POST | `/api/equip` | `{ itemId }` |
| POST | `/api/unequip` | `{ slot }` |
| POST | `/api/use` | `{ itemId }`。遗迹蛋会契约遗迹精灵 |
| POST | `/api/storage` | `{ itemId, direction: "deposit"\|"withdraw", count }` |
| POST | `/api/skills` | `{ ids: [四个当前武器的技能] }` |
| POST | `/api/shop/buy` | `{ npcId, itemId, count }` |
| POST | `/api/shop/sell` | `{ itemId, count }` |
| POST | `/api/craft` | `{ recipeId }` |
| POST | `/api/travel` | `{ mapId }`。人必须已经在世界里，且当前在城镇或正要离开副本 |

背包 60 格，仓库 80 格。满了的奖励进邮箱，用 `/api/mail/claim` 领。

## 灵伴与派遣

| 方法 | 路径 | 主体 |
| --- | --- | --- |
| POST | `/api/pets/active` | `{ petId }` 或 `{ petId: null }` 收回 |
| POST | `/api/dispatches` | `{ petId, nodeId, durationId }` |

登录、注册和游客入口太密时返回 429，正文仍是 `{ "error": "试得太频繁了" }`。

## WebSocket `/ws?token=`

客户端发：

```json
{ "type": "input", "x": 0, "y": 1, "destX": 420, "destY": 640 }
{ "type": "target", "id": "怪物实例" }
{ "type": "skill", "slot": 1 }
{ "type": "skill", "slot": "dodge" }
{ "type": "skill", "slot": "pet" }
{ "type": "guard" }
{ "type": "capture" }
{ "type": "interact" }
{ "type": "mode", "mode": "assistant" }
{ "type": "chat", "channel": "world", "text": "晚上好" }
{ "type": "chat", "channel": "party", "text": "这边集合" }
```

`guard` 让角色进入一拍守势。已经在守势里时这条消息会被忽略。人如果正在回合战斗里，这条消息改成防御。

开战和回合动作：

```json
{ "type": "engage" }
{ "type": "bout", "action": "attack" }
{ "type": "bout", "action": "skill", "slot": 1 }
{ "type": "bout", "action": "item", "itemId": "物品实例" }
{ "type": "bout", "action": "defend" }
{ "type": "bout", "action": "flee" }
```

`engage` 使用当前目标。快照在开战期间多一个 `bout`：回合数、阶段、是否轮到你、出手顺序和状态剩余回合。队友的顺序项带 `companion`，他们的动作由服务器选。自身还有 `worldX`、`worldY`。`gates` 是这张图边上的门。`chunks` 是当前地块和成对相邻地块的世界原点、宽高。`camera` 是镜头横向看见的世界宽度。副本的 `chunks` 只有自己。

## 摆摊和当面交易

| 方法 | 路径 | 主体 |
| --- | --- | --- |
| GET | `/api/stalls` | 附近摊位，含界边对面的摊 |
| GET | `/api/stall?id=` | 某一摊的货物 |
| POST | `/api/stall/open` | `{ title }`，2 到 8 个字 |
| POST | `/api/stall/list` | `{ itemId, count, price }`，价格是这一摞的总价 |
| POST | `/api/stall/unlist` | `{ id }` |
| POST | `/api/stall/close` | 收摊并退回货物 |
| POST | `/api/stall/buy` | `{ id, count }`，要站在摊旁边。买家付标价里这一部分，卖家到手扣 `marketTax`，向下取整 |
| GET | `/api/trade` | 当前交易窗，没有就是 `null` |
| POST | `/api/trade/invite` | `{ name }` |
| POST | `/api/trade/offer` | `{ itemId, count }` 或 `{ gold }` 或 `{ remove }` |
| POST | `/api/trade/lock` | 锁住自己这一栏 |
| POST | `/api/trade/confirm` | 两边都锁定之后再确认，两边都确认才成交 |
| POST | `/api/trade/cancel` | 取消，物品不动 |

`x`/`y` 是单位方向，服务器会把它收成最多 1，再乘角色速度。点地走路用 `destX`/`destY`。键盘方向会盖过点地。

服务器推：

- `snapshot`：自己的血蓝金币、同屏实体、冷却剩余毫秒、这一拍的伤害和掉落文字。自身还带 `swing`（距下次普攻的毫秒）、`guard`（守势剩余毫秒）、`interval`、`speed`、`beats`（当前目标上已经打出的普攻拍数）。伤害事件可以带 `guarded`
- `dirty`：请重新拉档案
- `dialog`：NPC 台词和按钮
- `toast`：失败原因或升级
- `world`：天气和时段
- `chat` / `news`
- `replaced`：这个角色的连接被新窗口接管。旧窗口应停止重连。关闭码 `4001` 是同一件事的备用信号；令牌无效或还没有角色时关闭码是 `4003`

助手模式 `mode: "assistant"` 之后，角色不再被选为仇恨目标，也不再自动攻击。
