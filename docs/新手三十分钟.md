# 新手三十分钟

这条线是主线前半。交付上一环会自动接下一个；等级不够的后续会留在委托人处。

| 时间感 | 任务 | 玩家在做什么 |
| --- | --- | --- |
| 0 分钟 | 初抵星落 | 游客或注册后站在星落镇。走近镇长艾兰，按 E，交付 |
| 2 分钟 | 走向翠叶 | 从西门或航标进入翠叶森林。林守就在入口北侧，和他交付 |
| 5 分钟 | 史莱姆成灾 | 打 5 只史莱姆。凝胶会掉 |
| 8 分钟 | 凝胶成药 | 背包里有 3 个凝胶后，打开制造，做史莱姆药剂。配方在铁匠那里，人在森林也能做 |
| 12 分钟 | 林间契约 | 森林猫在空地。打到三成血以下，按 C 或「契约」。下雨更容易 |
| 20 分钟 | 野猪暴走 | 南边的狂暴野猪。奖励里有一件精良衣服 |
| 25 分钟 | 带回星落，然后派遣 | 回镇找艾兰，再找旅团官莎雅。把森林猫派去翠叶药圃 |
| 30 分钟 | 旅团归来、自由市场 | 时间到了领取。短途侦察只要 1 分钟。然后把材料挂上拍卖行 |

领取时有不小的机会拿到「神秘地图碎片」，并让艾兰出现支线「矿洞鼠的发现」。这是挂机反过来生成主动内容的第一版。

再往后主线按等级打开：10 级月光湖和湖蛇，15 级赤岩和铁矿巨剑，20 级雷鸣峡谷，25 级风鸣高地、古代遗迹和幼年天空鲸，30 级回镇复命。支线散在林守、渔夫、矿头、铁匠和布鲁克那里，包括狗骑士、月光猫、公会捐献和仓库。

每天不要一次塞满红点。第一版用主线把系统一个个打开：战斗、制造、契约、派遣、拍卖，然后才是下一张地图。
